## 输出约定（给 merge / compose）

- kind：好的操作 → `好`；另一种思路 → `思路`；合理代价、回合主因 → `判定`；ECO-02 的 moment → `问题`；势头和总评 → `势头`。
- 全队层面的命中：`subject = '全队'`，`is_user = False`。
- `facts['slot']` 写明这条该进哪一栏：`moment`、`economy.idea`、`main_cause`、`summary.momentum`、`summary.headline`、`summary.team`。
- 回合层面和全场层面的命中：`t = 0.0`、`tick = None`。全场层面的 `round` 填锚定的那个回合（转折点、势头点）。
- 用户自己的"另一种思路"（ECO-04 买冲锋枪的是你）：blame 写 `—`（不算错）。CONTRACT 的 blame 取值里没有"另一种思路"。
- ECO-08 默认 blame 是 `队友或团队`。`facts['blame_you_if'] = ['POST-03','POST-04','POS-01']`：这一回合这几条判了你的责任时，由 merge 改成 `你的责任`。eco.py 看不到别的模块的命中。

## 在 rules_v1 之外加的处理（需要确认）

1. **赢下来的回合不再提"另一种买法"**：ECO-01 (B)(C)、ECO-02、ECO-03 的偏离分支，那回合赢了就不出，debug 记一行。原因是会和 ECO-07"低配翻盘"写在同一回合，读着矛盾（用户规则：看起来矛盾的结论不要放在一起）。例子：bd125285 R4 eco 赢下全起，ECO-02 本来会说"另一种思路是强起"。第 3 场不受影响。ECO-04 不受影响，R11 赢了照样出，这是 fires 里期望的。
2. ECO-04 除了规则写的第 13、14 回合，第 1、2 回合也排除，和对标口径（sit_players 去掉 1/2/13/14）一致。
3. COST-01 判"身上有没有长枪"：facts 层没有 inventory，用三样近似：买枪时的主武器、死前捡过的枪、这回合开过的枪。只要有一样是冲锋枪以上的档位，就算有长枪。
4. ECO-02 的"下回合{只够勉强起枪 | 也全起不了 | 才刚够全起}"按买枪时能推算的钱写（人均 − $300 + 下一档败方奖励），不用下回合的实际钱，这是 P1。第 3 场推算 $4490，实际 $4070，两种算法落在同一档。
