## 已知局限

- “往包点走”“离包距离”用了包的 3D 位置（下包人下包那一刻的位置），只用来判断方向，不进句子。
- POST-03 的回防路线只有每个包点两个固定参考点（post.json lanes），只看朝向、不算遮挡，所以写“朝着”。
- POST-01 “拉出去”靠 timeline user_fights 的 engage；没有这次对枪记录时只看“往包点走”。
- POST-02 “你只剩半血”是用户自己的血量（他自己知道），不是对方血量；如果 validate 用宽的“只剩.*血”正则会误报，需要只查对方血量。
- 只有第 3 场有人工基准；其他场只做了抽查。
