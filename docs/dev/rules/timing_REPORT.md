## 和原型 / rules_v1 不同的地方

1. **TIME-G1（decisions #25）**：
   - 信号只取你当时能拿到的：①敌方道具在目标区起爆、你听得到（C-HEAR 3D ≤ 2000，起爆点高度从 cache 的 `ev_*_detonate` 配）；②击杀栏里有队友在目标区阵亡；③雷达上同时有 ≥2 个 T 在目标区；④新增：你听得到目标区里 T 开枪（C-HEAR）。
   - 出发减信号 ∈ [0, 4] 秒（原来 [−1, 4]）。
   - 去掉“之后在目标点下包或目标区死 ≥2 个 T”的事后确认。
   - 补上 rules_v1 写了、原型没做的“出发时另一侧还有活着的队友”。
   - “从信号到到达目标区没有队友阵亡”：信号本身就是队友阵亡时，不把这次算进去（原型会把自己的信号算进去，信号②永远不可能命中）。
   - 句子写信号，不写结果。雷达信号写成“A 区同时出现两个 T”，不写“雷达上看到”。
2. **TIME-05**：交火开始前已经死了的开枪人，他的枪声不算。a32a2106 R6 的枪声来自你刚打死的 对手3（第2场），原来会误报。第一枪停稳了的不判（模板只有“第一枪还没停稳 / 一枪没开”两种，原型的第三种写法“撞上人后没能先打中”去掉）。“没先打中”只看凶手（rules_v1 原文），原型看的是打中任何人。
3. **TIME-02**：rules_v1 的条件①“进来时 CT 的火还在烧”是必须满足的（原型只拿来写句子）。
4. **报点**：一律用 common.place_cn（超市、跳台……）；中英文之间补空格（“VIP 的烟”“在 A1 等了”）。
5. **人数**：C-ALIVE（击杀栏），TIME-01 取这次击杀之后（`tick+1, lag_s=0`）。
6. **买法**：common.buy；“长枪局” = 全起，“长枪或强起” = 全起 / 半起 / 强起，“eco 局”（TIME-05 小问题）= 我方 eco / 强起 / 半起，并且对面全起。
7. **alt**：只取 rules_v1 alt，去掉括号里的知识库编号和对标说明（编号放进 `kb`）。
8. **下包点**：timeline 的 `plant.site` 只在第 3 场是 A/B，别的 demo 是包点实体号（'326'、'357'……）；这里按下包人报点（BombsiteA/B）换算。
