## 按 decisions 做的决定

### POS-01（decisions #10）
- 间隔 = 杀完到挨第一枪；挨枪后还在他枪线上、`pos01_follow_s`（1.5 秒）内被同一个人打死（或继续挨他的枪）的，算到最后一下。这样 R14 是 1.4 秒（和用户说的一致），R13 是 0.35 秒。
- ≥0.8 秒：没收句式，你的责任。不按阵营降责。
- <0.8 秒：不说"没收"，改看第一枪的站位：取打死他的那一串的第一枪（C-FIGHT bursts），要求①第一枪到击杀你没挪开（3D ≤100）②这段时间 A 那边打得到你：spotted / 互瞄，或者 A 的准星离你胸口 ≤10° 的帧占一半以上（R13 对手1 一直压着你的位置，但 spotted 一帧都没记到，只能靠这个兜底）。两条都满足才出站位句式；不满足（他是后来才走进来的）不出。A 之前没露过面记"小问题"（rules_v1 原写法，decisions 没改这一条）。
- 狙空（事件②）不在 decisions #10 的范围里，保留 rules_v1 的没收句式（R8 空枪后 0.3 秒、0.4 秒连挨两枪）。另外：狙空那一枪就是对着 A 开的（C-TARGET + C-SEEN 成立）时，算"你刚看到过他"，不写"一直没露过面"。

### POS-06W（decisions #23，替换 POS-06③）
- 触发沿用 ③：CT、在 A 点/A 楼梯/Jungle 或 B 点/小推车/B 后巷/超市、没下包、我方 ≥3 人；身边 3D 1000 内没队友，没有队友看到凶手，没被补；回看 tk−3 到 tk+5 秒有 ≥3 个敌人到过 1000 内。
- 三件事：
  1. 信息：守点人先看到对面的人（spotted 早于第一次挨枪 ≥1 秒），或者先打中对面。
  2. 拖时间：第一次接触（他看到人 / 被看到 / 对着来的人开枪 / 互相打中，最早一个）到倒下，≥8 秒算拖住。开枪只算对着来的人开的（C-TARGET），开局试枪不算（bd125285 R17 就有一枪 1.8 秒的试枪）。
  3. 人头和伤害：打死 ≥1 个，或者打掉 ≥100 血。
- 定责：做到 ≥2 件 → 合理代价（弱守的代价）；守点人是队友 → 不到 2 件就是队友或团队；守点人是你 → 1 件小问题、0 件你的责任。
- 其他 CT（第一次接触前 5 秒到接触时）：在 forward 报点（中远、A1、A 二楼、B 二楼、下水道……）= 出招；离守点人近了 ≥300 = 往这边靠；远了 ≥300 = 往另一边靠；其余 = 守别处。只写进句子当原因，不改责任。
- 句式：`{守点人} 一个人守{地点}，回看对面来了 {n} 个人；{他先看到了对面的人 | 他先打中了对面 | 他没有提前拿到信息}，{从第 x 秒第一次接触到第 y 秒倒下拖了 z 秒 | 第 y 秒一接触就被打死}[，第 p 秒对面下包]，{打死 k 个人、打掉 d 血 | 打掉 d 血，没打死人 | 没打到人}；当时 {谁在哪出招 / 谁正往这边靠 / 谁在往另一边靠 / 谁在守别处}。{守点人该做的……做到了，一个人守点被多人打穿是弱守的代价 | 一个人守点，……没做到}`
- alt：做到 ≥2 件："继续这样守：先拿信息、再拖时间，等队友回防再一起打"；没拿到信息："还可以先找个能早看到人的位置拿信息，看到人就往后收、用道具拖时间，等队友回防再一起打"；拿到信息但没拖住："还可以拿到信息后先往后收、用道具拖时间，等队友回防再一起打"。
- 第 3 场 R12 47.8 队友C：他先打中了对面，但第一次接触 0.8 秒就倒下、只打掉 50 血，做到 1 件 → 队友或团队（和 review 原来写的"队友"一致；rules_v1 曾改判合理代价，这里按 decisions 的评价方式回到队友）。

## 其他实现说明
- blame 只用 CONTRACT 的 6 个值；rules_v1 的"你的责任（小问题）"写成"小问题"。kind：POS-01..05 问题（合理代价分支写成判定），POS-06/06W/07/08 判定（守点人或死者是你、且是你的责任时写成问题），G1/G2 好。
- POS-02 合理代价例外（CT 已下包、离爆炸 ≤12 秒）句尾加"包快炸了，只能去拉，这次算合理代价"，第 3 场没出现。
- POS-06 ①② facts 里带 `suppress: ["TEAM-05","TEAM-06"]`，merge 时压掉同一次阵亡的这两条；merge_key = `death:<回合>:<死者 sid>`（POS-06W 同）。
- POS-02 merge_key = `killer:<回合>:<凶手 sid>`，给 TEAM-03 连杀合并用（M5）。
- POS-G2 次要命中（只是挪开、之后没在新位置拿到人）照样输出，`facts.primary=false`；rules_v1 说次要命中只计入 SUM-03（AWP 会换位的强项），不单独成为时刻。
- 句子排版：中文和英文名/数字之间补空格、两个中文字之间不留空格（"你又从同一条线"、"在 A 二楼"），和 rules_v1 例句一致。
- 为了躲开 validate 的"度"：alt 里的"换个角度/还没清过的角度"改成"换个位置/还没清过的方向"，证据里的"高度差很大"改成"一个在上一个在下"。
