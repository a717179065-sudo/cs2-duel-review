## Hit 约定（给 merge / compose）

- `facts.display`：`moment` 单独成一个时刻；`note` 只作那个时刻的附注（SHOT-01 / SHOT-05 打死了他的）；`summary` 只计入 SUM-01/02；`merged` 已合进同一串另一条规则的句子（`facts.merged_into`）。主句的 `facts.also` 列出合进来的规则。
- `facts.clause`：本条作从句时的半句。
- 同一串开枪的 SHOT-01/02/03/05 共用 `merge_key = shot:<回合>:<第一枪 tick>`；SHOT-04 用 `snipe:<回合>:<tick>`；SHOT-G1..G4 用 `kill:<回合>:<击杀 tick>`（M3 同一击杀只夸一句靠它）。
- `death_t / death_of`：没打死他，并且最后一枪后 2 秒内死了、或 3 秒内被这个人打死，才挂到这次阵亡上。
- blame：SHOT-01 打死了他、也没先被他打中 → `小问题`（附注）；SHOT-05 → `小问题`；SHOT-03 手枪 25 米外 → `合理代价`；其余问题 `你的责任`；好的操作 `—`。
- 时刻：开枪类取第一枪（G1、G3 同样）；SHOT-G2 取打死他的那一枪；SHOT-G4 取击杀 tick。
- “这次死本身算合理代价”（M2）没有写进 SHOT-01 句子：要等别的规则判了合理代价才加，由合并层接。
